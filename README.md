## 📖 简介

你是否遇到过这些情况：

- 随手打了一句「帮我写个东西」，AI 却连续反问三轮才搞清楚你要什么？
- 科研问题里术语用得不准，AI 顺着错误的表述一本正经地跑偏？
- 提示词写得客气又冗长，Token 烧了不少，回答质量却平平？

**Prompt Optimizer** 就是为此而生。它是一个可安装的 AI 技能（Skill），能把任何口语化、不完整、随意的自然语言输入，自动改写为**结构清晰、信息完备、Token 高效**的高质量 Prompt —— 让 AI **一次就给出可用结果**，大幅减少来回澄清的轮次。

它融合了 **Anthropic 官方提示词工程最佳实践**，内置**科研**与**代码**双场景模板库，并且会在改写前自动推断你的角色与意图、对高专业性课题先自学习领域知识再动笔。

## ✨ 核心功能

### 🧠 用户画像与颗粒度自动对齐

从对话上下文中静默推断你的**角色身份、专业深度、真实目的、期望效果**，自动匹配沟通颗粒度：

| 颗粒度档位 | 适用对象 | 生成 Prompt 的策略 |
|---|---|---|
| 粗 | 新手 / 探索阶段 | 要求 AI 先给方案选项再展开 |
| 中 | 常规任务 | 直接完整执行 |
| 细 | 专家 / 紧迫任务 | 高信息密度，跳过解释直接交付 |

无需填写任何表单，画像判断会在交付时附上一句话说明，方便你纠正误判。

### 🔬 领域知识自学习（科研场景）

面对高专业性科研课题，技能会**先自学习，再改写**：

1. 提取核心领域关键词，检索近两年综述校准认知；
2. 核对标准术语、主流技术路线、常用数据集与评价指标、公认基线与开放问题；
3. 消化为「领域速览卡」，据此修正术语偏差、填入准确的基线与指标、设定真实可达的验收标准。

> 例如你说「整整单细胞测序批次效应的东西」，它会自动校准为以 scVI/scANVI 为主线、Harmony 为基线、scIB benchmark 为评测体系的专业 Prompt。

### 🏗️ Anthropic 官方提示词工程体系

内置 11 条官方核心技巧，按需选用而非堆砌：

- **清晰直接黄金法则** —— 把 AI 当作「聪明但没有背景的新员工」
- **XML 标签结构化** —— 多成分复杂 Prompt 用 `<instructions>/<context>/<examples>` 分区
- **正向表述** —— 告诉 AI 做什么，而非禁止什么
- **可计数硬约束** —— 「150 字内、3 条要点」优于「简洁一点」
- **少样本示例、引用锚定防幻觉、提示词链拆分、思考与自检、风格镜像** 等

### 📚 双场景模板库

- **科研场景 ×7**：文献综述、选题打磨、实验设计、论文润色、统计分析、审稿、摘要写作
- **代码场景 ×7**：新功能、修 Bug、代码审查、重构优化、代码讲解、自动化脚本、架构选型

每个场景都带「口语输入 → 优化输出」的完整对照示例。

### 📊 Token 开销对比

附带 `token_stats.py` 脚本，一键估算优化前后的 Token 差异，效果量化可见。

## 🚀 使用方法

### 安装

1. 下载本仓库中的 `prompt-optimizer.skill` 文件；
2. 在支持 Skill 的 AI 平台（如 Kimi）中安装该技能。

### 触发方式

安装后无需记忆任何命令，以下说法都会自动触发：

- 「帮我优化这个 Prompt：……」
- 「把这段话改成给 AI 的指令」
- 「怎么问 AI 比较好」
- 直接粘贴一段想发给 AI 的粗糙想法

### 效果示例

**输入（口语）：**

> 你好，麻烦你帮我写个东西哈，能把文件夹里一堆图片压缩一下，太大了微信发不出去，谢谢！

**输出（优化后的 Prompt）：**

```
任务：写一个 Python 命令行脚本，批量压缩指定文件夹中的图片。
技术栈：Python 3.10+，仅用 Pillow。
需求细节：
- 输入：文件夹路径（命令行参数），处理所有 jpg/png/webp，含子文件夹
- 输出：在 compressed/ 目录存放结果，保持原文件名和目录结构
- 压缩目标：单张 ≤ 1MB，最长边 ≤ 1920px，JPEG 质量从 85 起逐步下调
- 边界情况：跳过已达标的文件；损坏文件报错但继续；最后打印统计
输出：完整可运行脚本 + 一行使用示例。
完成前对照需求逐项自检。
```

客套话删掉了，缺失的规格补全了，验收标准明确了 —— AI 一次就能给出可直接运行的答案。

## 💡 为什么值得用它

> **好的 Prompt 不是礼貌，而是精确。**

每一次模糊的提问，都在用后续的澄清轮次偿还利息。Prompt Optimizer 把「想清楚再问」这件事自动化了：它替你补全上下文、校准术语、对齐颗粒度、压缩冗余 —— 你只管说出想法，剩下的交给它。

无论你是在赶毕设的学生、追前沿的研究者，还是和产品经理赛跑的工程师，**让每一次和 AI 的对话都一次命中**。
