# 科研场景 Prompt 模板库

针对科研高频任务的优化模板与示例。使用时：匹配最接近的场景 → 套骨架 → 把用户原始信息填入 → 按 SKILL.md 第 6 步压缩。高专业性课题先按文末"领域自学习协议"校准再改写。

## 场景索引

1. 文献综述 / 领域调研
2. 选题与研究问题打磨
3. 实验设计 / 方法论
4. 论文润色与改写
5. 数据分析与统计
6. 论文评审 / 批判性阅读
7. 摘要、引言、投稿信写作

---

## 1. 文献综述 / 领域调研

骨架：

```
任务：围绕【研究主题】做一份结构化文献调研。
范围：【学科/子领域】，时间范围【年份区间】，重点关注【方向/方法/流派】。
产出要求：
1. 该领域的核心问题与演进脉络（3-5 个阶段）
2. 代表性工作对比表（作者/年份/方法/贡献/局限）
3. 当前未解决的开放问题
4. 与【我的研究方向】的切入点建议
约束：区分"确定的事实"与"你的推测"；不确定的文献信息标注[需核实]。
```

**示例**

输入（口语）："我想了解一下大模型推理加速这块最近都搞了些啥，我打算做这方面毕设。"

输出（优化后）：

```
任务：对"大语言模型推理加速"方向做结构化文献调研。
范围：2022 年至今，重点关注：量化、KV-Cache 优化、投机解码、蒸馏四条技术路线。
产出要求：
1. 各技术路线的核心思路与演进脉络
2. 代表性工作对比表（方法/加速比/精度损失/硬件条件）
3. 各路线当前的瓶颈与开放问题
4. 针对本科/硕士毕设规模，推荐 2-3 个可切入的具体问题，说明所需资源
约束：先摘引原文关键句再放入分析（引用锚定）；不确定的论文信息标注[需核实]，不要编造文献。
```

## 2. 选题与研究问题打磨

骨架：

```
角色：你是【学科】领域资深研究者，熟悉顶会/顶刊选题标准。
任务：评估并打磨我的研究问题。
我的初步想法：【一段话描述】
已有条件：【数据/设备/导师方向/时间周期】
请输出：
1. 对该想法的评价（新颖性、可行性、风险），直言问题
2. 3 个改进后的研究问题表述，各配一句话说明改进逻辑
3. 每个问题对应的最小可行验证实验
约束：不要客套，直接指出弱点。
```

## 3. 实验设计 / 方法论

骨架：

```
任务：为以下研究问题设计实验方案。
研究问题：【一句话】
假设：【可证伪的假设】
条件：【数据集规模/算力/时间/基线方法】
请输出：
1. 实验设计（自变量、因变量、控制变量、对照组）
2. 评价指标及选择理由
3. 基线对比方案
4. 消融实验设计
5. 可能的混淆变量与应对
约束：方案须在【条件】内可执行。
```

## 4. 论文润色与改写

骨架：

```
任务：润色以下【英文/中文】学术文本，目标期刊/会议风格：【名称或风格】。
原文：
【粘贴文本】
要求：
1. 只改语言不改学术含义；术语保持一致
2. 提升逻辑衔接与句式多样性，避免口语化表达
3. 输出格式：先给润色后全文，再用表格列出主要修改（原文/改后/理由）
约束：不新增引用，不改变数据与结论。
```

## 5. 数据分析与统计

骨架：

```
任务：为我的研究数据选择合适的统计分析方法并解读。
研究背景：【一句话】
数据结构：【变量类型、样本量、分组、是否配对】
分析目的：【检验什么假设 / 探索什么关系】
请输出：
1. 推荐方法及适用性理由（含前提假设检验）
2. 具体执行步骤（附 Python/R 代码）
3. 结果解读模板与常见误用提醒
约束：若数据条件不满足某方法前提，明确指出并给替代方案。
```

## 6. 论文评审 / 批判性阅读

骨架：

```
角色：你是【领域】的会议审稿人（如 NeurIPS/CVPR 风格）。
任务：评审以下论文【摘要/全文/某节】。
论文内容：【粘贴】
请输出：
1. 一句话总结贡献
2. 优点（最多 3 条）
3. 弱点与质疑（按严重度排序，每条指出具体位置）
4. 可复现性评估
5. 总体评分与理由
约束：批评须具体，禁止泛泛而谈。
```

## 7. 摘要、引言、投稿信写作

骨架：

```
任务：根据以下信息撰写论文【摘要/引言/投稿信】。
论文信息：【研究问题/方法/关键结果数字/结论】
目标：【期刊/会议名称】，字数限制【】
要求：
1. 结构符合该 venue 惯例（摘要按背景-问题-方法-结果-结论）
2. 关键数字必须出现在结果句中
3. 先给正文，再附 3 个备选标题
```

---

## 科研通用要点

- 学术 prompt 里**数字最值钱**：样本量、指标、年份、版本号，保留并前置。
- 涉及文献引用时永远加"不确定的标注[需核实]"，并要求先摘引原文再作答（引用锚定，官方最强防幻觉手段）。
- 要求 AI "直言问题/不要客套"能显著提升评审类输出质量。
- 润色类任务必须声明"不改变学术含义"，防止 AI 改坏结论。
- 调研→提纲→写作→审校这类多阶段任务，按提示词链拆成多个有序 prompt 交付，每步可验证可修正（见 official-techniques.md 第 10 节）。

## 领域自学习协议

高专业性科研任务的改写前置步骤。目标：**先搞清楚这个子领域"行话怎么说、活怎么干、水平线在哪"，再动笔改 prompt。**

### 领域速览卡格式

自学习结果压缩成这张卡（≤10 行，内部使用，不交付给用户）：

```
术语校准：用户说的"【口语表述】"→ 领域标准术语"【标准术语】"（是否等价/有偏差）
主流路线：【方法A / 方法B / 方法C】（近2年综述确认）
常用数据集：【名称+规模】；常用指标：【指标名及含义】
公认基线：【baseline 方法】；当前 SOTA 量级：【大致数字区间】
开放问题：【1-2 个公认难点】
不确定项：【检索未能确认的内容，标[需核实]】
```

### 速览卡如何校准 prompt

| 卡片字段 | 校准动作 |
|---|---|
| 术语校准 | 替换 prompt 中的口语/错误术语；若用户表述有歧义，prompt 里写明标准术语并括注用户原词 |
| 主流路线 | 填入"范围/路线"槽位，防止 AI 漏掉重要分支或编造不存在的路线 |
| 数据集与指标 | 填入 `[规格]` 槽位；用户没提数据时，以该领域标准基准作为默认占位 `[待补充：默认用 XX 基准？]` |
| 基线与 SOTA | 校准验收标准：把"达到先进水平"改成该领域真实可达的数字区间，防止定出不可能或过于宽松的目标 |
| 开放问题 | 用于选题/调研类 prompt 的"切入点"槽位，确保推荐方向是真问题而非已被解决的 |

### 完整示例

输入（口语）："帮我整整单细胞测序那个批次效应的东西，我想用深度学习做，问 AI 要个方案。"

自学习检索后得到速览卡：

```
术语校准："单细胞测序"→ scRNA-seq；"批次效应"→ batch effect 校正/数据整合（data integration）
主流路线：scVI/scANVI（深度生成模型）、Harmony（嵌入校正）、scVI 系为深度学习主流
常用数据集：PBMC、HCA 基准；常用指标：scIB benchmark（LISI、Silhouette、ARI、kBET）
公认基线：Harmony、Scanorama；SOTA：scVI 系在 scIB 榜单领先
开放问题：校正强度与生物信号保留的权衡
```

校准后的 prompt：

```
任务：为 scRNA-seq 数据整合（批次效应校正）设计一个基于深度学习的实验方案。
背景：课题方向为单细胞转录组分析，拟采用深度生成模型路线。
规格：以 scVI/scANVI 为主线，Harmony、Scanorama 为基线；
     评测采用 scIB benchmark 指标体系（LISI、Silhouette、ARI、kBET）；
     基准数据 [待补充：默认用 PBMC + HCA 公开基准？]
请输出：
1. 方法设计（模型结构、损失函数、批次标签的使用方式）
2. 实验设计：对照设置、消融实验、scIB 各指标的预期目标区间
3. 关键风险：校正强度与生物信号保留的权衡，及验证手段
约束：不确定的方法细节标注[需核实]；方案须在单张 24G 显卡上可复现 [待补充：确认算力]。
```

对比不改写的版本——"用深度学习去除单细胞批次效应的方案"——校准后的 prompt 补全了方法路线、基线、评测体系和算力约束，AI 一次即可给出可执行方案。

### 纪律

- 检索上限 1-3 轮；优先近两年综述（survey）而非单篇论文。
- 只校准 prompt 的槽位，不替用户做研究、不输出调研报告。
- 检索不到或不确定的内容标 `[需核实]`，绝不虚构术语、数字或方法名。
